# Security Policy

## Reporting a vulnerability

Email **security@gantrydeploy.com**. Please do not open a public GitHub issue, pull request, or discussion for a suspected vulnerability.

Include as much of the following as you can:

- The affected version of `@gantrydeploy/cli` (`gantry --version`) and your Node.js version and OS
- A description of the issue and its impact
- Steps to reproduce, or a proof of concept
- Any logs or output that help, with tokens, credentials, and other secrets removed
- Whether you would like to be credited, and how

## What to expect

- **Acknowledgement** within 3 business days of your report.
- **Initial assessment** within 10 business days, including whether we have confirmed the issue and its expected severity.
- **Coordinated disclosure** within 90 days of the report. We will agree a disclosure date with you, and may ask to extend it if a fix needs more time. Please keep the details private until then.

## Supported versions

Only the latest published release of `@gantrydeploy/cli` receives security fixes. Upgrade to the latest version before reporting, where you can.

## Scope

This policy covers the code in this repository and the `@gantrydeploy/cli` package published to npm. Issues in the Gantry platform or API may also be reported to security@gantrydeploy.com.
